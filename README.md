## Flask Information Storage 

According to the Flask documentation here: https://flask.palletsprojects.com/en/stable/quickstart/, a session allows us to store info that is specific to a user from one request to the next. This is implemented on top of cookies and signs cookies cryptographically. To use sessions, we need a secret-key (which is also required to modify cookie contents here). Logging out wipes the session, which makes it forget all the previous info.
